# File Maker - Svelte App

A simple Svelte app that lets you create and download files by typing the file name, extension, and content.

## Features

- Input a file name (without extension)
- Choose or type any file extension (e.g., txt, js, html)
- Enter the content of the file
- Download the file instantly

## How to Use

1. Open the app.
2. Type your desired file name.
3. Enter the file extension.
4. Write or paste the file content.
5. Click the download button to save the file to your device.
